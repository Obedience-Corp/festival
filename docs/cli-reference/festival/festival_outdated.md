## festival outdated

Check installed packages for available updates

### Synopsis

Refresh installed sources and check versions without installing or restarting anything.
Reports per-package errors when availability cannot be checked. External installs keep their existing update route.

```
festival outdated [flags]
```

### Options

```
      --allow-unverified   allow checking unsigned content
  -h, --help               help for outdated
      --json               emit JSON output
```
