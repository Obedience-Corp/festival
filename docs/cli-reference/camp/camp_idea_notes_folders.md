## camp idea notes folders

List note folders

### Synopsis

List every note folder under .campaign/intents/notes/.

Order: notes root, reserved folders (meetings, archived), then user folders
alphabetically depth-first.

Examples:
  camp idea notes folders
  camp idea notes folders --json
