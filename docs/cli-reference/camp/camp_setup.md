## camp setup

Create your first festival camp once

### Synopsis

Create and register a camp named festival in your configured camps directory when you have no registered camps. Existing camps are preserved. Once setup succeeds, deleting the starter does not cause it to be recreated. Failed setup can be retried with the same command.

```
camp setup [flags]
```

### Options

```
  -h, --help   help for setup
      --json   Emit the setup result as JSON
```
