## obey top

Live session cockpit for the current campaign

### Synopsis

Interactive fleet view of all agent sessions in the campaign: live status, drill-in attach, and approvals.

```
obey top [flags]
```

### Options

```
  -c, --campaign string   campaign name or UUID (defaults to current directory's campaign)
  -h, --help              help for top
```
