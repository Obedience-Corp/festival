## festival setup

Create your first festival camp once

### Synopsis

Create your starter camp using the installed Camp. Existing camps are preserved. Run this after a package-manager install or to retry starter setup.

```
festival setup [flags]
```

### Options

```
  -h, --help   help for setup
      --json   emit JSON output
```
